
DOCUMENT TITLE: Change or Reset Your Microsoft Account Password in Windows
SOURCE: Microsoft Support
CATEGORY: Accounts & Access
APPLICABILITY: Windows

OVERVIEW

Users can change or reset their Microsoft account password through Windows or the Microsoft password-reset page.

The recovery procedure depends on whether the user is:
- Not signed in to Windows.
- Already signed in using a Microsoft account password.
- Signed in using a PIN.
- Using a local Windows account.

RESET A FORGOTTEN MICROSOFT ACCOUNT PASSWORD

If the user forgot their Microsoft account password and cannot sign in to Windows, they can reset it using one of the following methods.

METHOD 1: FROM THE WINDOWS SIGN-IN SCREEN

1. Open the Windows sign-in screen.
2. Select I forgot my password.
3. Follow the instructions to verify the account and reset the password.

METHOD 2: USING WEB SIGN-IN

1. On the Windows sign-in screen, select Sign-in options.
2. Select Web sign-in.
3. Follow the prompts to sign in.
4. Select Forgot my password.
5. Follow the account recovery instructions.

METHOD 3: USING A WEB BROWSER

1. Open a web browser.
2. Navigate to the Microsoft password-reset page.
3. Follow the instructions to verify the account.
4. Create a new password.

CHANGE A KNOWN MICROSOFT ACCOUNT PASSWORD

If the user is already signed in to Windows and knows the current password, they can change it through Settings.

STEPS:

1. Open the Settings app.
2. Select Accounts.
3. Select Sign-in options.
4. Select Password.
5. Select Change.
6. Enter the current password.
7. Follow the instructions to create a new password.

IF THE USER FORGOT THE CURRENT PASSWORD

If the user is already signed in but forgot the password:

1. Open Settings.
2. Select Accounts.
3. Select Sign-in options.
4. Select Password.
5. Select Change.
6. Select Forgot my current password.
7. Follow the instructions to verify the account and create a new password.

MICROSOFT ACCOUNT PASSWORD RECOVERY WHEN USING A PIN

A user may sign in to Windows using a PIN even if they have forgotten their Microsoft account password.

If the user knows their PIN, they can use Windows Settings to change the Microsoft account password.

STEPS:

1. Open Settings.
2. Select Accounts.
3. Select Sign-in options.
4. Select Password.
5. Select Change.
6. Follow the instructions to reset or change the password.

CHANGE OR RESET A LOCAL ACCOUNT PASSWORD

Local Windows accounts have a different password recovery procedure from Microsoft accounts.

If the user forgot the local account password, it can be reset from the Windows sign-in screen using the configured security questions.

STEPS:

1. At the Windows sign-in screen, select the arrow next to the password field.
2. Select OK.
3. Select Reset password.
4. Answer the security questions configured when the local account was created.
5. Follow the instructions to create a new password.

IMPORTANT NOTES

- Microsoft account and local account password recovery procedures are different.
- Users can reset a forgotten Microsoft account password from the sign-in screen or through a web browser.
- Users who know their Windows PIN may still be able to change their Microsoft account password through Settings.
- Local account password recovery requires previously configured security questions in the procedure described by Microsoft.
- Microsoft Support agents cannot retrieve or bypass a lost or forgotten password.
- Microsoft Support agents cannot send password-reset links or access and change account details on behalf of users.
- If the normal recovery options do not work, users can use Microsoft's Sign-in helper.
